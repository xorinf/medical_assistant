#### Medical Assistant 
> A clinic management system for coordinating patients, doctors, receptionists, lab staff, and administrators. The application must support appointment scheduling, electronic medical records, prescriptions, lab orders, invoices, and follow-up workflows.
MedAssist – Clinic Operations & Patient Care Portal
Tech Stack: MERN (MongoDB, Express.js, React, Node.js)  •  AI-Enabled Capstone
Description
Develop a clinic management system for coordinating patients, doctors, receptionists, lab staff, and administrators. The application must support appointment scheduling, electronic medical records, prescriptions, lab orders, invoices, and follow-up workflows. AI should assist clinicians with structured summaries and help patients understand non-diagnostic medical instructions.
Roles and Responsibilities
Role	Responsibilities
Clinic Admin -	Configure the clinic, manage users, services, schedules, billing settings, and reports.
Doctor -	Manage appointments, clinical notes, diagnoses, prescriptions, and follow-up plans.
Receptionist -	Register patients, schedule appointments, manage queues, and handle basic billing workflows.
Lab Technician -	Manage lab orders, sample status, results, and result verification.
Patient	- Manage profile, appointments, prescriptions, reports, invoices, and follow-up requests.
Features
•	Secure authentication, RBAC, session management, and audit logging.
•	CRUD for patients, doctors, departments, services, appointments, medical notes, prescriptions, lab orders, results, and invoices.
•	Appointment calendar with doctor availability, rescheduling, cancellation, queue status, and conflict detection.
•	Patient timeline combining appointments, notes, prescriptions, investigations, and billing records.
•	Lab workflow from order creation to sample collection, processing, verification, and patient release.
•	Role-specific dashboards and strict access controls around patient records.
•	AI integration: convert structured visit notes into a concise clinical summary for clinician review.
•	AI integration: explain prescription/follow-up instructions in plain language without making diagnoses or changing treatment.
•	Search, filters, notifications, document uploads, printable reports, and immutable activity history.
Capstone expectation: Implement the project as a complete MERN application with REST APIs, MongoDB data modeling, React routing/state management, server-side validation, error handling, secure authorization, responsive UI, and meaningful test data.
